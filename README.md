# java-lotto-precourse

## 기능 정리

- 로또 금액(immutable)
    - 1000원 단위
    - 예외
        - 1000원단위로 나누어떨어지지 않는 경우
        - 양의 정수가 아닌 경우
        - 최댓값(1,000,000) 보다 큰 경우

- 로또(immutable)
    - 1개당 1000원
    - 번호 6개
    - 번호 뽑는 로직
    - 예외
      - 번호 개수가 6개가 아닌 경우
      - 특정 번호가 1~45 범위를 넘을 경우
      - 중복된 번호가 있을 경우

- 로또 생성기
    - 가격 계산해서 해당 개수만큼 로또 인스턴스 만들기
    - 인스턴스를 Lottos 객체에 넣어서 리턴

- 입출력
    - 로또 금액 받기
    - 당첨 번호 받기
    - 보너스 번호 받기

    - 랜덤 발행된 번호 출력
    - 결과 출력

- 로또 시스템
    - 각 로또마다 당첨 여부 확인하기
    - 당첨 결과 저장
